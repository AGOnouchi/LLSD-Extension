# Love Love School Daysを買いましょう！！！！！！！！！！<br>
https://store.steampowered.com/app/1305300/%E3%83%A9%E3%83%96%E3%83%A9%E3%83%96%E3%82%B9%E3%82%AF%E3%83%BC%E3%83%AB%E3%83%87%E3%82%A4%E3%82%BA/

■ 配布内容<br>
LLSD Extension本体、VRM読み込み用ランタイム、導入スクリプト、説明書、第三者ライセンス<br>
※利用可能なVRMモデルは各自で用意してください。モデル固有の利用条件はそのモデルの条件に従ってください。

■ 必要なもの<br>
・Love Love School Days（steam）<br>
・BepInEx 5 x64（動作確認に使用したバージョン：5.4.23.5）<br>
  配布元：https://github.com/BepInEx/BepInEx/releases<br>
・Humanoid VRMファイル<br>
検証環境はゲームVERSION 2.0.0 / Unity 2021.3.22f1です。<br>
VRM 0.xは変換して読み込みます。VRM 1.0の読み込み処理も含みますが、すべてのVRM・拡張仕様の動作を保証するものではありません。

■ 導入<br>
1. ゲームを終了します。<br>
2. BepInEx 5 x64の「BepInEx」というフォルダを、LoveLoveSchoolDays.exeがあるディレクトリにフォルダごと配置し、ゲームを一度起動＆終了します。<br>
3. Install.cmdを実行します。<br>
  ※Steamのライブラリから自動でゲームを検出します。見つからない場合はゲームフォルダーを入力してください。<br>
   ゲームフォルダーはSteamの「管理」→「ローカルファイルを閲覧」で確認できます。<br>
4. ゲームを起動し、F9→「VRMを読み込む」から自分のVRMを選びます。

MOD更新時、導入スクリプトは既存MODフォルダーを<br>
ゲームフォルダーの BepInEx/mod-backups/ へ退避します。設定ファイルは維持します。

手動導入：ゲームを終了し、既存の上記MODフォルダーをpluginsの外へ退避したうえで、<br>
配布物の BepInEx/plugins/LLSDExtension フォルダーをゲームの同じ場所へコピーしてください。<br>
BepInEx本体を含むゲーム内ファイルを配布物で上書きする必要はありません。

■ 操作<br>
F5：時間割を強制切り替え<br>
F6：カメラ位置に光源を設置<br>
F7：最後に設置した光源を削除<br>
Shift＋F7：設置した光源をすべて削除<br>
F8：VRM置き換えの有効・無効<br>
F9：設定メニュー<br>
F10：フリーカメラ<br>
フリーカメラ：WASDで移動、Q/Eで上下、左Shiftで高速移動、右ドラッグで回転、ホイールで画角変更。<br>
F9またはフリーカメラの使用中は、通常の操作キャラの移動・視点操作を止めます。

■ 主な機能<br>
・マキナのVRM置き換え（オープニング・イベント・徘徊など）<br>
  ※デフォルト衣装のみが対象<br>
・サイズ変更（0.2～3倍）、高さ調整、位置合わせ設定<br>
・自動表情・口パク転送、手動表情（手動時は元モデルから口の動きのみ転送）<br>
・VRMSpringBone対応<br>
・表示姓名の変更（空欄可）<br>
・ゲーム速度（0～3倍）、フリーカメラ、最大16個の設置光源<br>
・時間割の強制切り替え

■ 設定の保存先<br>
ゲームフォルダー/BepInEx/config/local.makina.vrmswap.cfg<br>
既存設定を引き継ぐため、MOD名変更後も従来のファイル名を使用しています。<br>
VRMファイルのフルパスは [Model] セクションの Path に保存されます。<br>
例：<br>
[Model]<br>
Path = D:\Models\Avatar.vrm<br>

F9でVRMを選び直すと、この値も更新されます。<br>
設定ファイルを手動編集するときはゲームを終了してください。<br>
この設定ファイルにはVRMモデルパスと変更した姓名の設定を保存します。<br>

■ 削除・元に戻す<br>
ゲーム終了後、BepInEx/plugins/LLSDExtension を取り除くと本MODを無効にできます。<br>
設定も初期化する場合は local.makina.vrmswap.cfg を退避または削除してください。<br>
旧版へ戻す場合は、mod-backupsの必要な旧フォルダーをpluginsへ戻してください。

■ 問題がある場合<br>
ゲームを終了してから導入し直し、旧版が重複していないことを確認してください。<br>
モデルの違い・イベントの違いで見た目や表情の対応に差があります。<br>
問い合わせ時はMODバージョン、ゲームバージョン、発生場所、倍率、位置合わせ設定、再現手順を添えてください。<br>
詳細なエラーはゲームフォルダー/BepInEx/LogOutput.logに記録されます。<br>
ログには利用者のファイルパスが含まれる場合があるため、公開前に内容を確認してください。
