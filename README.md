■ 配布内容
LLSD Extension本体、VRM読み込み用ランタイム、導入スクリプト、説明書、第三者ライセンス
※利用可能なVRMモデルは各自で用意してください。モデル固有の利用条件はそのモデルの条件に従ってください。

■ 必要なもの
・Love Love School Days（steam）
・BepInEx 5 x64（動作確認に使用したバージョン：5.4.23.5）
  配布元：https://github.com/BepInEx/BepInEx/releases
・Humanoid VRMファイル
検証環境はゲームVERSION 2.0.0 / Unity 2021.3.22f1です。
VRM 0.xは変換して読み込みます。VRM 1.0の読み込み処理も含みますが、すべてのVRM・拡張仕様の動作を保証するものではありません。

■ 導入
1. ゲームを終了します。
2. BepInEx 5 x64の「BepInEx」というフォルダを、LoveLoveSchoolDays.exeがあるディレクトリにフォルダごと配置し、ゲームを一度起動＆終了します。
3. Install.cmdを実行します。
  ※Steamのライブラリから自動でゲームを検出します。見つからない場合はゲームフォルダーを入力してください。
   ゲームフォルダーはSteamの「管理」→「ローカルファイルを閲覧」で確認できます。
4. ゲームを起動し、F9→「VRMを読み込む」から自分のVRMを選びます。

MOD更新時、導入スクリプトは既存MODフォルダーを
ゲームフォルダーの BepInEx/mod-backups/ へ退避します。設定ファイルは維持します。

手動導入：ゲームを終了し、既存の上記MODフォルダーをpluginsの外へ退避したうえで、
配布物の BepInEx/plugins/LLSDExtension フォルダーをゲームの同じ場所へコピーしてください。
BepInEx本体を含むゲーム内ファイルを配布物で上書きする必要はありません。

■ 操作
F5：時間割を強制切り替え
F6：カメラ位置に光源を設置
F7：最後に設置した光源を削除
Shift＋F7：設置した光源をすべて削除
F8：VRM置き換えの有効・無効
F9：設定メニュー
F10：フリーカメラ
フリーカメラ：WASDで移動、Q/Eで上下、左Shiftで高速移動、右ドラッグで回転、ホイールで画角変更。
F9またはフリーカメラの使用中は、通常の操作キャラの移動・視点操作を止めます。

■ 主な機能
・マキナのVRM置き換え（オープニング・イベント・徘徊など）
  ※デフォルト衣装のみが対象
・サイズ変更（0.2～3倍）、高さ調整、位置合わせ設定
・自動表情・口パク転送、手動表情（手動時は元モデルから口の動きのみ転送）
・VRMSpringBone対応
・表示姓名の変更（空欄可）
・ゲーム速度（0～3倍）、フリーカメラ、最大16個の設置光源
・時間割の強制切り替え

■ 設定の保存先
ゲームフォルダー/BepInEx/config/local.makina.vrmswap.cfg
既存設定を引き継ぐため、MOD名変更後も従来のファイル名を使用しています。
VRMファイルのフルパスは [Model] セクションの Path に保存されます。
例：
[Model]
Path = D:\Models\Avatar.vrm

F9でVRMを選び直すと、この値も更新されます。
設定ファイルを手動編集するときはゲームを終了してください。
この設定ファイルにはVRMモデルパスと変更した姓名の設定を保存します。

■ 削除・元に戻す
ゲーム終了後、BepInEx/plugins/LLSDExtension を取り除くと本MODを無効にできます。
設定も初期化する場合は local.makina.vrmswap.cfg を退避または削除してください。
旧版へ戻す場合は、mod-backupsの必要な旧フォルダーをpluginsへ戻してください。

■ 問題がある場合
ゲームを終了してから導入し直し、旧版が重複していないことを確認してください。
モデルの違い・イベントの違いで見た目や表情の対応に差があります。
問い合わせ時はMODバージョン、ゲームバージョン、発生場所、倍率、位置合わせ設定、再現手順を添えてください。
詳細なエラーはゲームフォルダー/BepInEx/LogOutput.logに記録されます。
ログには利用者のファイルパスが含まれる場合があるため、公開前に内容を確認してください。
